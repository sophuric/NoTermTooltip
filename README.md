### Fabric mod to hide item tooltips in SkyBlock Dungeons Floor 7 terminals

The item tooltip can be very obstructive in some terminals, so this mod hides it entirely for all terminals.

![3x3 Same Colour Terminal](https://github.com/sophuric/NoTermTooltip/raw/main/assets/3x3-term.png)
